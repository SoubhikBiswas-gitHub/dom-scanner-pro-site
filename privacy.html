DOM Scanner Pro privacy policy

Last updated: 23 October 2026. Applies to DOM Scanner Pro 2.0 and later.

DOM Scanner Pro is a developer and design tool that inspects web pages you choose. It works entirely in your browser. The developer does not run any server for it and receives no data from it.

What the extension reads

When you start inspection on a tab (by clicking the toolbar icon, using its shortcut, or allowing a site), DOM Scanner Pro reads that page's structure, computed styles and layout in your browser in order to show measurements. It reads page text where a feature needs it: a short preview of the selected element in the panel (you can turn this off), accessible names of controls, contrast and accessibility checks, and reference markup when you ask for it. That text stays in the panel's memory unless you choose to save or export it. It never reads form field values or passwords, and it removes text you are editing from reference markup.

Screenshots are taken only when you choose Capture, and only of the visible tab.

When you choose Copy (for example CSS, a selector or diagnostics), the text is placed on your clipboard. Nothing is copied without that action.

What it stores

Stored locally in your Chrome profile, and only on this device:

  • Settings (theme, preset, overlay options), in extension storage.
  • Findings you mark "Not an issue", in extension storage, grouped by site (the page's origin) and limited to 500 per site, so they stay dismissed on later scans. Each entry holds the rule, the element's short label and the measured value.
  • Saved reports, snapshots, checklists and project presets, in the extension's local database, only when you choose to save them. Screenshots are saved only after your redactions have been applied to the pixels.
  • Temporary session state (which tabs are being inspected, recent error codes), cleared when the browser closes.

Nothing is stored in Chrome sync. Local browser storage is not encrypted by the extension; anyone with access to your browser profile could read it.

You can delete everything at any time in Settings → Clear all DOM Scanner Pro data. Removing the extension also removes its stored data.

What it sends

Nothing. DOM Scanner Pro makes no network requests of its own: no analytics, no crash reporting, no accounts, and no remote code. Its pages run under a content security policy that blocks network requests (connect-src 'none'). The accessibility rules engine (axe-core) is bundled and runs locally with remote loading turned off. Addresses that appear inside measured CSS values (for example background images) have their query strings and fragments removed before they are shown, saved or exported.

Exports (Markdown, JSON, PNG and ZIP files) are saved through your browser's normal downloads and go only where you put them. By default they exclude the page address, query strings, page text, form values and personal details; you can choose to include the page origin and path.

The usage guide, this policy and the support page are included in the extension and open from Settings without going online. Links to the Chrome Web Store listing and to accessibility rule help (Deque University) open in a normal browser tab only when you click them.

Diagnostics for support are prepared only when you ask, shown to you in full, and copied or downloaded only if you choose. They contain the extension and Chrome versions, the platform, your settings, the state of current inspections (without page addresses), recent error codes, how many sites you have allowed and how much storage is used. They exclude page addresses, page content, screenshots, reports and the names of allowed sites. They are never sent anywhere automatically.

Permissions

  • activeTab and scripting: to read the tab you started inspection on, only after you act.
  • sidePanel: to show the workspace.
  • storage: to keep settings and dismissed findings locally.
  • Optional site access: requested only when you choose to allow a site or an embedded frame. You can remove it in Settings → Site access.

Data sharing and sale

DOM Scanner Pro does not collect personal data, so it does not sell, share or transfer any. It does not use data for advertising, creditworthiness or any purpose unrelated to inspecting pages.

Changes and contact

When this policy changes, the date at the top changes, and the release notes say what changed. Questions: see Support.
