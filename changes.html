Changelog

All notable changes to DOM Scanner Pro. Versions match the Chrome Web Store package.

2.0.4 — 23 October 2026

Fixed

  • Pending saves and imports cannot restore data after Clear all data; concurrent saves enforce the report limit atomically.
  • Reopened saved reports retain their draft, original observation context and page address across view changes.
  • Fractional screenshot redactions cover both edges completely, including reverse drags.
  • Clear all data removes in-memory report drafts and comparison state across open panels.
  • Activation and Stop wait for stored sessions to load before changing intent generations.
  • Contrast checks require review for gradients over opaque colours and ancestor compositing effects.

2.0.3 — 23 October 2026

Changed

  • Dropdowns have a clearer arrow with space on the right, a hover state, and long options end with an ellipsis instead of running under the arrow.

2.0.2 — 23 October 2026

Fixed

  • How to use, Privacy policy and Report a problem in Settings now open the usage guide, privacy policy and support page included in the extension, so they work offline. Previously they pointed to a page the public could not open. Support now goes through the Chrome Web Store listing.

Changed

  • The usage guide now lists what the extension cannot inspect, and the privacy policy covers clipboard copies and support diagnostics.

2.0.1 — 23 October 2026

Added

  • Focus mode dims everything on the page except the selected element. Turn it on in Settings › Overlay layers or from the command menu.
  • Findings you mark "Not an issue" are remembered for that site, so they stay dismissed the next time you scan. Clearing all data in Settings removes them.
  • A token file loaded in Review can be saved with a project preset and loaded again later.
  • The Selectors card says when the element is inside a frame, and which one.

Changed

  • Scans hand the browser back to the page more readily, so the page's own animations, timers and typing stay responsive while a scan runs.

2.0.0 — 23 October 2026

A complete rebuild. The extension keeps its name and store listing, and everything else is new.

Changed

  • Nothing runs on a page until you click the toolbar icon, press Alt+Shift+D, or allow a site yourself. The old version asked for access to every website and loaded on all of them.
  • Inspection now happens in a side panel, with a small overlay on the page. The overlay never restyles the page; pages that react to extra elements switch to panel-only inspection automatically.
  • The toolbar badge shows ON only after the page confirms inspection has started. It stays correct after navigation, tab closing, browser restarts of the extension's background worker, and updates.

Added

  • Inspect: size and position with a box-model diagram, typography with font status, flex and grid gaps, image and SVG details, text contrast, validated selectors, filtered computed styles, CSS rule sources, stacking and clipping explanations, and keyboard-only selection.
  • Compare: two pinned elements side by side, with measured differences in plain language, CSS to match, and saved snapshots for comparing staging with production.
  • Review: horizontal overflow, accessibility rules (axe-core, bundled), contrast, target sizes and labels, focus order walkthrough, design outliers, palette and type boards, CSS variables with token mapping, asset references, layout shift recording, viewport resizing, and checklists.
  • Reports: screenshots with permanent redaction, annotations, issue reports with four templates, and Markdown, JSON, PNG and ZIP exports. Saved locally only when you choose.
  • Task presets (Inspect, Design review, QA review, Learn), simple and advanced views, light and dark themes, a command menu (Ctrl/⌘ K), and a practice playground that works offline.

Removed

  • The "Share Feedback" button that appeared on inspected pages. Support is linked from the panel instead.

1.0 — 13 March 2025

  • First Chrome Web Store release: colored element outlines and a hover tooltip shown while holding Ctrl or Command.
