DOM Scanner Pro

DOM Scanner Pro is a Chrome extension that shows what the browser actually rendered, explains it in plain language, and turns it into evidence you can share. It is built for frontend engineers, designers, QA testers and anyone learning CSS.

Get it from the Chrome Web Store

What it does

  • Inspect: box model, visible and layout size, typography with the font stack, flex and grid gaps, image details, text contrast, selectors tested against the page, and computed styles you can copy.
  • Compare: pin two elements and see exactly how they differ, with CSS to match. Save snapshots to compare staging with production.
  • Review: horizontal overflow, accessibility rules (axe-core, bundled and run locally), target sizes, focus order, design outliers, CSS variables and token mapping, layout shift recording and checklists.
  • Share: screenshots with permanent redaction and annotations, issue reports, and Markdown, JSON, PNG and ZIP exports saved through your browser.

Private by design

  • Nothing runs on a page until you click the toolbar icon or use the shortcut.
  • No account, no analytics, no network requests and no remote code.
  • Reports are stored only in your browser, and only when you choose to save them.
